# Haarlem quiz

Kaartquiz om de wijken en buurten van Haarlem (en elke andere Nederlandse gemeente) te leren kennen.

Live: https://bathnelson.github.io/Haarlem-quiz/

- Alles draait in de browser; er is geen backend en er zijn geen API-sleutels nodig.
- Wijk- en buurtgrenzen komen live van de openbare CBS/PDOK WFS-dienst.
- Highscores en voortgang worden alleen lokaal in de browser (localStorage) bewaard.
- Multiplayer loopt peer-to-peer via PeerJS.
